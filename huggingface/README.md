# 🔮 AI 얼굴 관상 분석 서비스

얼굴 사진을 업로드하면 AI가 관상을 분석해주는 재미있는 웹 애플리케이션입니다!

## 사용 방법

1. 얼굴 사진을 업로드하세요
2. "관상 분석하기" 버튼을 클릭하세요
3. AI가 분석한 관상 결과를 확인하세요!

## 주의사항

⚠️ 이 서비스는 재미와 오락을 목적으로 만들어졌습니다.
관상 분석 결과는 참고용이며 과학적 근거가 없습니다.

## 기술 스택

- Google Gemini AI
- Gradio
- Python
